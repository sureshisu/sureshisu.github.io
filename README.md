# sureshisu.github.io

Personal academic website of Suresh Murugaiyan, hosted on GitHub Pages.

## Structure

| File | Page |
| --- | --- |
| `index.html` | About: biography, education, research interests |
| `research.html` | Research overview and projects |
| `publications.html` | Preprints, theses, and conference presentations |
| `experience.html` | Research appointments |
| `css/style.css` | Shared stylesheet |
| `img/` | Profile photo and figures |

Plain HTML and CSS with no build step. Edit the HTML files directly and push to `main` to deploy.
